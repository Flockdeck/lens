Fixes for enriching with Anthropic, and a stale-UI bug.

- A new optional Workspace ID in Settings (or `ANTHROPIC_WORKSPACE_ID`). An Anthropic key that is not tied to one workspace is rejected with a 400 unless the request names a workspace; with the ID set, lens sends it as the `anthropic-workspace-id` header. Leave it empty for a key that is.
- When Anthropic rejects a request, the failed item now says why (the API's error type and message) instead of only the status code. The message describes the request and holds none of the recording.
- The web UI files are now revalidated by the browser on each load. Before, a browser could keep running the old scripts after an upgrade, so a new Settings field could be missing until a hard refresh.

Run it with `lens serve --open`. Builds are for Windows, macOS and Linux on amd64 and arm64, signed with Flockdeck's release key and not code-signed.
