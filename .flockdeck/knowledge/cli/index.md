# CLI commands

* [lens check-storage](check-storage.md) - Writes, reads back and deletes a small probe file in the data directory to prove it is usable.
* [lens cleanup](cleanup.md) - Runs retention cleanup once, on demand; serve already does this on a timer.
* [lens serve](serve.md) - Runs the whole service in one process, with the web UI, HTTP API, enrichment worker and retention timer.
* [lens version](version.md) - Prints the program version and exits.
