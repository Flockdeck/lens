Rejected as `InvalidKey`: empty keys, NUL, backslash, colon (drive letters), non-canonical forms (`//`, `/./`, trailing slash), absolute paths, `.` or `..` parts, and any key that resolves (following symlinks) to the root itself or outside it. Keys are generated by the server, not taken from requests, so this is a second line of defence. Files are mode 0600 and directories 0700 on POSIX; on Windows the profile ACLs apply. Details in [filesystem store](/packages/storage-filesystem.md).
