First release of lens.

lens reads recordings of coding-agent sessions written by Flockdeck, works out what happened in each one, and shows it in a web page on your own machine. It is one program with nothing to install: no database server, no separate worker, nothing to sign in to.

What it does:

- Upload one or more recording files (`.jsonl`). It parses them, computes metrics (duration, turns, tool use, errors, permissions, time in each status), flags risky actions by rule, and lists the files touched.
- Optionally asks a model for a summary, category, outcome, a frustration estimate, where the agent got stuck, prompt feedback, and whether the model used suited the task. The default is a mock that sends nothing anywhere. A model running on your machine through Ollama works too. Anthropic is available if you choose it and give it a key; then a size-limited digest of each session is sent to Anthropic, and the page says so.
- Browse sessions, read the raw events, compare agents and models, and see trends.

Everything it keeps is in one folder (`%LOCALAPPDATA%\lens`, `~/Library/Application Support/lens` or `~/.local/share/lens`). Raw recordings are deleted after 30 days by default; the derived data stays.

Run it with `lens serve --open`.

Builds are for Windows, macOS and Linux on amd64 and arm64. They are signed with Flockdeck's release key, so Flockdeck can verify them, but they are not code-signed: expect a SmartScreen or Gatekeeper warning if you download one by hand.
